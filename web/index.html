WebAssembly Component Model demos

WebAssembly components built from various languages and toolchains.

Rust

Unless stated otherwise, all demos are built using wit-bindgen (wit_bindgen::generate!) and compiled using the wasm32-wasip2 target. Despite the name of the target, examples do not use WASI.

  • Hello, world
  • Calculator
  • Calculator (no WIT)
  • DOM traversal
  • String marshalling
  • Attribute churn
  • DOM query
  • Table update
  • Canvas draw
  • Canvas pixel transfer

C++

Examples are written in C++20 using bindings generated by wit-bindgen and compiled using clang's wasm32-wasip2 target, with no C++ standard library. Again, despite the target, WASI is not used. Equivalent Emscripten-based examples are also provided.

  • Hello, world
  • DOM traversal
  • Attribute churn

C

  • Hello, world
  • Calculator (freestanding)
  • Greet (freestanding)
  • Greet (libc)
  • Greet (wit-bindgen + wasip2)
